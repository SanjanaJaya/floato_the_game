## About Floato

After 2 months of intense development, we're proud to present our first mobile game: **FLOATO** — an endless arcade-style shooter built using **Flutter Flame**.

### Game Highlights:
- 🛩️ Face waves of enemy planes in an endless sky battle  
- 📍 Progress through 25 missions, each inspired by a district in Sri Lanka  
- 🐦 Unlock 8 unique birds, each with their own special fire powers  
- ⚡ Collect 4 powerful abilities to gain instant advantages mid-flight  
- 🌐 Supports both **English** and **Sinhala** languages  
- 🔊 Immersive sound effects and original background music for an engaging experience  

This project was created by a passionate 6-member team at **HORIZON FORGE STUDIOS**. FLOATO is a celebration of creativity, culture, and teamwork.

## Getting Started

This project is a Flutter application built using the Flame game engine.

### Prerequisites

- Flutter SDK installed  
- Dart programming knowledge (recommended)  
- Basic understanding of game development with Flutter Flame  

### Useful Resources

- [Flutter: Write your first app](https://docs.flutter.dev/get-started/codelab)  
- [Flutter Cookbook: Useful samples](https://docs.flutter.dev/cookbook)  
- [Flutter official documentation](https://docs.flutter.dev/)  

---

## How to Run

1. Clone the repo  
2. Run `flutter pub get` to install dependencies  
3. Run `flutter run` on your connected device or emulator
